2. Definition of the Protected Mechanism

For the purposes of attribution and protection, CIFA is defined as:

A deterministic computational system that approximates raster image data by decomposing it into ordered scalar slices and fitting continuous mathematical functions per slice, optionally modulated by global or local compensating fields, with measurable reconstruction error and compression characteristics.

This definition applies regardless of:

programming language

UI implementation

visualization method

execution environment

3. Scope of Protection

This authorization applies to the mechanism and method, not merely the source code.

Protected elements include:

The slice-based functional approximation pipeline

The separation of fitting, field modulation, and correction stages

The use of coefficient count as a compression proxy

The deterministic reconstruction pathway

The structural role of a compensating field applied post-fit

Re-implementations that preserve these core principles constitute derivative works.
